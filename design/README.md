# 設計稿

`*.dc.html` 是 Claude Design canvas 的 artboard 原始檔,`canvas.json` 是版面配置。

- `SwissC1.dc.html` — 定稿,對應 `src/pages/index.astro`
- `SwissC2.dc.html` — 加敘事區塊的變體(未採用)
- `Main.dc.html` / `Editorial.dc.html` / `SwissGrid.dc.html` / `Timeline.dc.html` — 最初的四個方向稿

改動版面前先改這裡,再重新產生 canvas,不要直接改打包後的 HTML。
